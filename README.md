# PropShow Paper Covers

以葵（Aoi）为主角的纸艺拼贴视频封面技能。每期默认交付 **16:9、4:3、9:16 三张独立构图**，保持标题、人物身份、配色和核心动作一致。

## 快速使用

在支持技能和内置图像工具的 Codex 环境中，让助手读取本目录的 [SKILL.md](SKILL.md)，再提供主题、标题或视频链接。仅将仓库放在磁盘上不代表技能已经被自动发现；未安装时可以直接指定文件：

```text
读取当前文件夹的 SKILL.md，使用其中的 PropShow Paper Covers 规则，
为「我的 AI 工作流」生成一期封面，分别交付 16:9、4:3、9:16 三张独立构图。
```

技能已经被环境识别时，可直接调用：

```text
使用 $artifact-template-propshow-paper-covers，为这个视频生成纸艺封面：<视频链接或主题>。
每期交付 16:9、4:3、9:16 三个版本。
```

只需要方案时，明确写「只输出提示词，不生成图片」。多期任务则提供主题或链接列表，默认 N 期交付 3N 张正式封面。需要读取链接时以可获取的正文或说明为依据，不把未观看的视频当成已观看。

## 从角色到三版封面的流程

### 1. 建立或更新形象（已有葵素材可跳过）

使用 `ip-illustration-character-system`，提供角色描述、已有图片或需要保留的身份特征，先生成设定图并选定一个版本。例如：

```text
使用 $ip-illustration-character-system，设计一个可长期复用的技术内容角色。
名字是葵（Aoi）：银灰碎发、低双马尾、薄荷发尾、绿眼，
角色自身左侧佩戴黑色薄荷 <> 发夹，炭黑敞开连帽衫、白色 >_ T 恤、深色长裤。
先制作角色设定图，包含全身和四种表情，保持同一人物和自然身材比例。
```

选定后保留批准原图，并用简短身份协议记录发型、脸、眼睛、配饰、服装与比例。需要更新本模板时，明确指定新的批准素材，再更新 `assets/aoi.webp` 和身份协议；仅试做的新图不要覆盖正式资产。需要共享角色库时，再使用 `rongbao-illustrations` 的注册流程，明确提供批准图片、中文名、英文 ID 和别名。

### 2. 确定封面内容

每期先确定一个短标题、一个核心动作、2–4 个必要道具及 2–4 个主色。让角色通过动作表达主题，例如连接工作流卡片、整理组件或检查工具，不只是站在标题旁边。

不同主题可以换配色、标题位置和人物尺度。纸艺参考用于统一材质，不要求始终采用浅蓝杏橙或左字右人的布局。避免为了装饰增加功能、数字或效果承诺。

### 3. 明确参考图职责

生成前实际查看参考图，并把原图作为图像输入；只写人物名称或文件路径不能代替图片输入。

1. **Image 1：`assets/aoi.webp`，identity reference only。** 控制角色身份，不复制整张设定表。
2. **Image 2：`assets/reference.png`，paper material reference only。** 控制纸面、边缘、叠层、光线，不复制原图标题与姿势。
3. 按需添加系列参考或已批准成品，说明只继承内容和视觉语言，需要重新构图。涉及具体产品时，附上经过查看的官方 Logo 素材，并清楚标注所属产品。

### 4. 逐张生成三个版本

| 比例 | 构图重点 | 可请求的尺寸示例 |
| --- | --- | --- |
| 16:9 | 充分利用横向空间，展开人物、标题与动作关系 | 1600×900 |
| 4:3 | 缩短视觉路径，调整标题换行与人物尺度 | 1600×1200 |
| 9:16 | 上部标题，中部人物与动作，道具沿纵向组织 | 1080×1920 |

每版分别调用内置图像工具，检查后再进行下一版。三版都使用原始角色和纸艺参考，不能靠裁切、拉伸或加边把一张图变成三张正式版本。缺少内置工具时说明情况，不自动切换到外部收费 API。

竖版可先按左右各 10%、顶部 10%、底部 20% 留出关键内容余量，并额外避开右侧互动栏。这是设计起点，**不是抖音官方规格**；平台的播放页、主页等入口可能使用不同遮挡和裁切，仍需在目标入口预览。

### 5. 验收与保存

分别检查中文、产品拼写、脸和手势、发夹方向、服饰、纸艺融合、背景密度和遮挡余量。具体产品的 Logo 必须来自可核验官方素材；取不到时只保留产品名，不凭记忆编造标志。

读取实际像素尺寸核对比例：16:9 应满足 `宽×9 = 高×16`，4:3 应满足 `宽×3 = 高×4`，9:16 应满足 `宽×16 = 高×9`。提示词写明尺寸不代表工具一定按该尺寸输出。失败时使用图像工具定向修正；仍失败则标明试图或未验收，不能用拉伸掩盖。

```text
outputs/propshow-paper-covers/
├── 16x9/01-topic-16x9.png  （另存同名 .jpg）
├── 4x3/01-topic-4x3.png    （另存同名 .jpg）
└── 9x16/01-topic-9x16.png  （另存同名 .jpg）
```

PNG 保留原稿，JPEG 由同一画面导出，不重新生成。修订时使用新文件名，不覆盖旧版。批量任务按比例提供总览、清单和 ZIP，并核对每期三版配对。生成封面不包含平台上传、修改视频标题或发布授权。

## 微调技法

这里的「微调」指参考图约束和定向图像编辑，不涉及模型训练。

### 锁住身份，只改一个问题

每次描述一个可检查的修改，明确保留已通过的标题、脸、配色、服装与材质。角色仍用原始身份图约束，避免连续只引用上一张生成图造成漂移。发夹在角色自身左侧，正面看位于画面右侧，不能随朝向任意镜像。

```text
以这张封面为编辑目标，同时附上葵原始身份图和纸艺参考。
只修正发夹：位于角色自身左侧，黑色底、薄荷色 <>。
保持脸、发型、服装、标题、动作、构图和配色不变。
```

### 缩小人物和道具，给竖屏留空间

发现右侧手势或底部道具容易被遮挡时，缩小并向中部重新安排主体，不只是添加一块空白边框。

```text
只调整 9:16 版构图：人物与道具整体缩小，将双手与三张卡片移入画面中部，
底部 20% 保持安静纸面，右侧避开互动栏。
保留原题字、脸部身份、配色、纸张纹理和连接卡片的动作。
```

### 让角色真正融入纸艺

人物像贴上去时，重点调整衣服、道具的纸张颗粒、剪纸边缘与投影方向；保留精细动漫五官，不用全局滤镜掩盖材质差异。

```text
只改善角色与场景的材质融合：衣服和道具呈现纤维纸面、克制叠层及一致的浅投影。
保持五官精度、角色身份、文字和布局不变，不增加碎纸、速度线或粒子。
```

### 改字时锁定文案，控制密度

逐字给出最终标题；画面拥挤时优先减少装饰、增加字号或调整换行，不新增解释性小字。同一期三版保持标题文字一致，允许换行不同。

```text
只修正标题，准确写为「我的 AI 工作流」，分成「我的 AI」「工作流」两行。
保持 PropShow 小字、人物、道具、颜色和纸艺质感不变，不添加其他文案。
```

### 有限迭代并记录结果

针对具体缺陷最多做两次定向迭代，保留原稿与修订稿，记录修改点、参考图、实际尺寸及验收状态。未达到要求时直接说明，避免反复生成导致已批准内容一起改变。
